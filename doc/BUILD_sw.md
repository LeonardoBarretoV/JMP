# doc/ -- model write-up with endogenous inflation

| file | what it is |
|---|---|
| `JMP_inflation_model.tex` | **the deliverable.** Standalone LaTeX, compiles with no `.bib`. |
| `JMP_inflation_model.pdf` | 13-page rendered PDF (built from the HTML below, not from the `.tex`). |
| `JMP_inflation_model.html` | the source the PDF was rendered from, math pre-split for KaTeX. |
| `checktex_sw.jl` | structural checker for the `.tex` (environments, braces, `$`, packages, labels). |

## Moving it into Overleaf

Paste the body between `\begin{document}` and `\end{document}` into the manuscript.
`biblatex` there will take over `\textcite`, and the `\defcite` shim in this
preamble becomes inert automatically (it is a `\providecommand`). The citation keys
used are the same ones already in the paper.

## Why the PDF was not built from the .tex

There is no TeX distribution on this machine (`pdflatex`, `xelatex`, `lualatex`,
`tectonic`, `latexmk` all absent). The PDF was produced by rendering the HTML twin
with KaTeX in headless Chrome:

```
julia <scratch>/prep.jl                     # splits \[..\] and \(..\) into spans
chrome --headless --disable-gpu --no-pdf-header-footer \
       --virtual-time-budget=30000 \
       --print-to-pdf=doc/JMP_inflation_model.pdf \
       file:///<scratch>/model_r.html
```

Render was verified before printing: **217 of 217 math elements rendered, 0 failures**
(25 display, 192 inline). The `.tex` has passed the structural checks in
`checktex_sw.jl` but **has not been compiled**, so treat the first Overleaf build as
the real test of it.

## Where the numbers come from

Every figure in Sections 4-6 is generated by `scripts/table6_consolidate_sw.jl` and
stored in `output/table6_sw.md` and `output/table6_sw.txt`, with per-run provenance in
`output/jld2_sw/<tag>.txt`. Nothing in the write-up was typed by hand from a transcript.
